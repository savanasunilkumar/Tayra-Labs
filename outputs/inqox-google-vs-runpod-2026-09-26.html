Google Cloud or RunPod for Molmo2?

Use the available Google Cloud startup credits for the first pilot if they cover Cloud Run GPU usage. Keep RunPod as a cost benchmark for the business after the credits expire.

26 September 2026 · USD list prices · One L4 GPU · No deployment or account inspection performed

Overview

Google Cloud is technically capable of hosting the Inqox inference worker. Cloud Run supports L4 GPUs, can scale to zero, and can serve requests from an asynchronous Cloud Tasks queue. RunPod was selected for the starter because its serverless queue matches the existing worker directly and its listed L4 rate is lower.

What changes in our architecture

Customer upload → Cloudflare API → private R2 stays the same. The Cloudflare API would enqueue work in Google Cloud Tasks; an authenticated Cloud Run GPU service would read the signed R2 source URL, run Molmo2, write the result to R2, and notify the API. D1 remains the job record. Cloud Run GPU Jobs are an alternative for longer isolated jobs, but loading a roughly 19 GB model for every individual job may consume credit quickly; benchmark that path before choosing it.

  1. Verify the promotional credit’s Scope and End date on Google Cloud Billing → Credits. A non-billable $300 free trial restricts GPU access; a paid billing account can use remaining eligible credit.
  2. Start with one Cloud Run L4, 4 vCPU, at least 16 GiB system RAM, minimum instances zero, maximum instances one, concurrency one, and non-zonal redundancy. Raise RAM or GPU size if Molmo2 video inference needs it.
  3. Store the pinned model in Cloud Storage for reliable starts; Google recommends this for large models. The current RunPod container and API integration need an adapter for Cloud Run and Cloud Tasks.
  4. Measure GPU seconds, cold start, memory peak, failures, and dollars per processed video hour on both providers before committing to a long-term host.
45% margin check: the current architecture notes a proposed $1.49 per processed video hour, allowing about $0.82 total cost per video hour. At list price, the minimum Google configuration could use at most about 47 GPU minutes per processed video hour before other costs; RunPod about 71 minutes. Promotional credits lower pilot cash spend, but do not establish a sustainable post-credit margin. A separate older pricing brief proposes different rates, so the launch rate card still needs reconciliation.

What not to overclaim

  • The exact $2,900 credit eligibility and expiry have not been verified from the billing account.
  • An L4’s 24 GB VRAM has not been proven sufficient for Molmo2 video inference at our five-minute limit.
  • Hourly GPU price is not cost per processed video hour; model speed and cold starts determine that conversion.
