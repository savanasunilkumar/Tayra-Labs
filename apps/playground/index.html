Your Tayra Labs workspace
This page connects to your existing IAM-private Google Cloud API through a local, authenticated bridge.
  1. Choose a video or load the public sample clip.
  2. Write a question and choose a response length.
  3. When analysis is enabled, select Analyze video. This uploads the video and submits a real, potentially billable job.
  4. Read, copy, or download the result. Refreshing the page lets you reopen saved job IDs.
GPU currently paused?
You can preview videos and read earlier results. This interface cannot resume the GPU or change your cloud budget. API connectivity does not mean a GPU is warm.
Sources have a normal 24-hour retention window and results 30 days, with asynchronous cleanup. Recent job IDs and filenames are stored in this browser; credentials are not.
